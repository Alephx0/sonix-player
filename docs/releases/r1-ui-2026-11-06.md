# HiBy R1 local Spotify-inspired UI — 2026-11-06

This release packages the local-only C/LVGL player tested on the connected HiBy
R1. It includes the accumulated local music and audiobook interface work and
removes the former online discovery, downloading, matching and verification
paths from the firmware application.

Latest repairs:

- Precompute the current and next waveform in a bounded background worker and
  retain results on SD. The first uncached analysis still takes time.
- Preserve Now Playing geometry while switching Line/Waveform at Normal/Large.
- Keep the Library fast-scroll grip within the filtered list viewport.
- Share case/accent folding between alphabetical ordering and the A-Z indicator.
- Estimate missing release types: seven or more local tracks -> Albums;
  fewer -> Singles & EPs. Explicit tags and manual overrides take precedence.

## Validation and scope

Native waveform, discography and collections suites passed. Real 480 x 800 SDL
interaction tests passed at Normal and Large, including repeated waveform style
changes, seeking, Artists-only fast scrolling and release-type override/reset.
R1 tests confirmed background waveform preparation, a prepared next waveform,
and jumps through 842 artists with no audio write recoveries in the sampled log.

The player was tested on-device from SD; this exact update image has not yet
been flashed. This is a hardware-scoped prerelease, not a claim of compatibility
with every R1 revision or AIC8800 radio board. Startup scanning, initial artwork
decode and distant Library jumps can still pause; no smartphone frame-rate
guarantee is made. Missing-type estimates can misclassify partially imported
releases. See [UI audit](../UI_AUDIT.md) and
[packaging notes](../custom-firmware/hardware-and-packaging.md).

## Install on the tested R1 setup

Copy `r1.upt` to the root of the microSD card. Open **Settings -> Device -> System
-> Update from SD card** and confirm. Keep the player charged and the card
inserted throughout the update. This package is not for the R3 Pro II.
